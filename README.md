# 🔐 React Custom CAPTCHA (No API)

A lightweight CAPTCHA system built using React without relying on external services like Google reCAPTCHA.

This project demonstrates how to create a basic human verification system using canvas rendering, random text generation, and simple validation logic.

---

## 🚀 Features

- ✅ No external API required  
- 🎨 Canvas-based CAPTCHA (with noise & distortion)  
- 🔄 Refresh CAPTCHA  
- ✔️ Input validation  
- ⚛️ Built with React  

---

## 📸 Preview

Canvas-based CAPTCHA with random characters and noise lines.

---

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/mounir2025b-droid/react-custom-captcha.git
cd react-custom-captcha
npm install
npm start
```

## 🧠 How It Works

- A random string is generated  
- The string is drawn on an HTML canvas  
- Noise lines are added to make it harder for bots  
- User inputs the text  
- Input is validated against the generated CAPTCHA
